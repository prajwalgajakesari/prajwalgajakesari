## 👋 Hey, I'm Prajwal

I'm an engineer who ships small, focused tools, usually because I wanted them to exist and they didn't.
Most of my work sits at the intersection of **data platforms**, **Apple-native apps**, and **AI tooling**, with a steady stream of motorcycle side projects.

- 🍎 Writing **SwiftUI** apps for macOS and iOS
- 🤖 Building **MCP servers** and **Claude Code plugins** so AI assistants can actually *do* things
- 🗄️ Running data platforms on **Trino**, **Azure Data Lake** and **Purview**
- 🏍️ Riding, and building software for riders

|:--|:--|:--|
| [**DiskLens**](https://github.com/prajwalgajakesari/disklens) | Native macOS disk-space visualizer and cleaner with a Liquid Glass UI. A free, open-source take on CleanMyMac's Space Lens, with safety colour-coding so you never delete the wrong thing. | Swift · SwiftUI · SPM |
| [**The Vault, AI Edition**](https://github.com/prajwalgajakesari/the-vault-ai) | A daily AI newsletter, researched and published every morning: 15 to 20 stories on models, research, business and policy. | Markdown · HTML · automation |
| [**claude-music**](https://github.com/prajwalgajakesari/claude-music) | A `/music` slash command for Claude Code. Play, pause, skip and search Apple Music, or tune into Claude FM, without leaving the terminal. | Shell · AppleScript |
| [**gmaps2gpx**](https://github.com/prajwalgajakesari/gmaps2gpx-cli) | Turn Google Maps direction URLs into GPX files. Handles shortened links, dragged routes, alternative routes and a motorcycle routing mode. | Python · Google Routes API |
| [**Azure Purview MCP**](https://github.com/prajwalgajakesari/Azure_Purview_MCP) | An MCP server that lets an AI assistant search, read and update Azure Purview data-catalog metadata. | TypeScript · Azure |
